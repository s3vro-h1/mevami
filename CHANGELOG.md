# Changelog

## [0.2.1] - 2026-10-19
### Added
- Filter songs by video (🎬 Has Video) and by lyrics (🎤 Has Lyrics), they can be combined with each other and with the other filters.
- Lyrics badge on songs, next to the video badge.
- Lyrics detection in the scanner (chart events, MIDI vocal tracks, and the `lyrics` tag in song.ini).

### Notes
- If you're upgrading, delete `scan_cache.json` and run the scanner once so your existing songs get their lyrics info.

## [0.2.0] - 2026-05-19
### Added
- Sorting by difficulty lvl
- Customizing theme interactively
- Guitar Hero Live instruments are showing now too.
